\textit{EEGAVI} is a multimodal architecture built on frozen backbone encoders for each input modality.
The frozen representations are further elaborated before passing through a \textit{cross-attention} mechanism.
\textit{EEG} is the main modality of the model acting as a \textit{pivot} while the others are \textit{supports}.
This structure allows the model to generalize well even with limited or absent supporting modalities.
Like other representation models, \textit{EEGAVI} outputs a \textit{CLS} token that condenses sample information into a tighter space.
The token is used during training for contrastive alignment
and is also the main tool for the realization of downstream tasks.
The model's default implementation is able to process: EEG, video, text, audio, and ECG data.

\section{Data}
For the development of the model, different multimodal datasets  were used.
Not all of the selected  modalities are present in all datasets.
This limitation acts as regularizer in the training pipeline and makes the model robust to missing data.

\subsection{Sampling Strategy}
Affective responses unfold across multiple temporal scales, for this reason the model must generalize well on both short events and longer temporal dynamics.
While short clips may capture localized affective outbursts, long ones can encode the evolution of a subject's perception over time.
For the model to be robust across scales we sample variable-length EEG segments between 1 and 32 seconds using an EEG-centric sampling strategy.

Segment durations are sampled from a log-uniform distribution, favoring shorter clips.
A sample is taken at random from the clip with probability $p$ or selected as a point of interest from the signal with probability $1-p$.
In the experimental setup $p=0.3$.
When an \textit{anchor} point is selected, short segments are built by centering on it.
Longer segments are built in the same way by centering directly on an existing anchor.
If the resulting segment respects the overlap constraints defined for that class, it is stored as a sample, otherwise it is discarded.

The process is iterated until it fails to present new valid segments after running out of settable patience threshold.

The candidate extractor first computes \textit{Short Time Fourier Transform (STFT)} based frame features per EEG channel.
The points of interest are extracted in the STFT domain following a set of heuristics commonly used when processing EEG.
These anchors are identified through a multi-descriptor scoring mechanism that combines the following indicators:
\begin{itemize}
% TODO Cite these
    \item \textit{Relative band power per frame}: Fraction of total spectral power contained in predefined frequency bands.
    Sudden dominance of a specific band indicates that a change in the oscillatory regime contributes positively to the salience.
    In the context of \textit{EEG} analysis in the affective domain, common
    values for the bands include delta(0.5–4 Hz), theta(4–8 Hz), alpha(8–13 Hz), and beta (13–30 Hz).
    For this reason, these default values were adopted in the experiments. % todo cite
    % https://www.sciencedirect.com/science/article/pii/S2590005621000205
    % https://www.sciencedirect.com/science/article/pii/S2405844024075169

    % todo enrich all these?
    \item \textit{Spectral entropy}: Shannon entropy of the normalized power spectrum; high when the spectrum is flat (distributed energy); low when concentrated.
    Lower entropy is favored, as it indicates structured spectral content rather than broadband noise.

    \item \textit{Spectral flux}: Frame-to-frame positive spectral change computed on magnitude spectra, capturing rapid spectral dynamics.
    Rapid spectral changes are rewarded in the saliency extraction process.

    \item \textit{Root-mean-square (RMS)}: Measures the average signal energy in a window, regardless of the frequency content.
    Higher energy contributes positively to candidate selection, as it highlights strong neural responses.

    \item \textit{Line length}: It is a simple time-domain EEG feature that measures the total amount of change in the signal within a window.
    It computes the average absolute first difference, acting as a proxy for the signal's complexity.
    In EEG it is often associated with high activity such as seizures/epilepsy or motion artifacts; therefore, its contribution is moderated in the scoring process.

    \item \textit{Teager–Kaiser Energy Operator (TKEO)}: It captures bursty, high-frequency energy.
    Sensitive to rapid changes, it is popular in EEG analysis; adds robustness to the process as it might capture patterns not recognized by RMS alone.
\end{itemize}

Afterward, each channel's features are standardized with a rolling median/MAD estimator with a 30 seconds window.
This is done to prevent high-variance features from dominating the saliency score, mitigating the effect of outliers.
A saliency score per channel is formed as a weighted sum of z-scored features.
These scores are aggregated by taking the mean of the top $k=40\% $ of input channels.
Artifact annotations are used to downweight candidate frames before anchor selection.
Lastly, a greedy top-score selection with a minimum time gap constraint is applied to select the points.

\subsection{Preprocessing}
Each modality is processed individually.
All modal streams pass through their relative encoder directly in preprocessing for computational constraints and memory efficiency reasons.
This is because the various modalities are spatially expensive to load on the hardware and the passage through an embedding model would be a computational overhead in each iteration.
Given this limitation, it is impossible to compute training augmentations on demand, and thus the idea was dropped entirely.
Pre-processing is done for both \textit{EEGAVI} and \textit{VATE}, each with their own pipeline.

Given the intrinsic temporal structure the data have, a sample's modalities are partitioned into smaller time blocks on which the embedding model is called.
To avoid the excessive storage growth, sequence resampling is performed to generate segments that will act as temporal unit tokens.

All modalities that are encoded in floating point are also symmetrically quantized in $int8$ with a per-dimension scale vector to further reduce the space load.

Knowing that media can occasionally be missing and that segments following the defined sampling strategy can vary in size, all modalities of a single sample are masked on the time axis.
This choice allows for both varying sequence length to be elaborated while also allowing modalities to be completely absent for samples in the model.

\subsubsection{EEG (pivot)}
It is the main modality of the model.

As described when introduced, \textit{CBraMod} works on the relative spatial arrangement between the measuring electrodes.
So, for it to work correctly, each dataset must first be mapped into a common channel layout.
This is called the canonical order and it becomes part of the model definition as it has to be consistently applied across datasets.
The pretrained \textit{CBraMod} instance from the developers was used as backbone for this modality, and while the research team that proposed it affirms that it can handle unseen channels this leads to degradation in quality of the embeddings.
For this reason, the layout used from \textit{EEGAVI} is the same as the one by the frozen encoder adopting the \textit{10-20} system for electroencelography.
The canonical order used by the project is reported in table \ref{tab:eegorder}.
All datasets are mapped into this canonical channel order; missing electrodes are zero-filled and masked.

The signal must also be resampled ($fs=200$) to generate one-second tokens by \textit{CBraMod}.
For EEG handling and preprocessing, the \textit{MNE} \cite{} library was used.

For \textit{EEGAVI} to work, all supporting modalities have to match the same time unit size which is set to 4 seconds.
This is not necessary for \texit{EEG} as the\textit{pivot} interaction with other modalities comes later in the architecture allowing for a flexible temporal structure.
For this reason \textit{EEG} is set to respect the encoder's granularity of one second patches.

\subsubsection{Video}
Video is a modality available in all datasets.
All experiments share a similar setup where the image is centered on the face of the subject.
For this reason, no cropping to the input videos was performed except for the pretrained \textit{VATE} pipeline, where this step was part of its original definition.

The selected backbone for the Video embeddings is ViViT\footnote{ViViT pretrained instance: google/vivit-b-16x2-kinetics400} \cite{arnab2021vivitvideovisiontransformer}.
To preserve spatial-temporal richness of the encoder its \textit{last\_hidden\_state} output was used.
The raw output is high-dimensional and memory intensive, a single sample is of the shape $(16, 14, 14, 768)$ which is then repeated for $T$ time steps.
To solve this problem, $2D$ pooling is applied on the $(14,14)$ frames with $stride=3$ and $kernel=3$.

\subsubsection{Audio}
All audio, when present, is turned into a mono signal and resampled to match the required $fs=16kHz$ by the WavLM\footnote{WavLM pretrained instance: microsoft/wavlm-base} \cite{Chen_2022} encoder.
It is primarily a speech/paralinguistic model which might limit generalization to non-verbal vocalizations.
\textit{EAV} tracks speech of the subject but \textit{AMIGOS}'s audio does not have the participant as direct interlocutor.
Future work could evaluate alternative audio encoders or separate speech vs. reaction audio streams.

\subsubsection{Text}
No dataset provides a textual transcript of its experiments.
For this reason, speech is obtained using \textit{Whisper}\footnote{Whisper pretrained instance: openai/whisper-medium} by OpenAI\cite{radford2022robustspeechrecognitionlargescale}.
The process is only possible when an audio track is available and the duration of the media is shorter than 5 minutes.
Whisper is able to process longer clips but the need for timestamps on the extracted words makes this unfeasible computationally.

\subsubsection{ECG}
They measure the activity of the cardiovascual system.
These measurements are often versatile, as it is possible to reconstruct more of the signal even if the measurements are limited.
They also are strictly related to brain activity and are to physiological processes associated with affective state.
As an ECG foundation model, the ECG-FM\cite{mckeen2025ecgfmopenelectrocardiogramfoundation} was chosen.
It is reported to perform well when the data channels are incomplete.
This makes it a strong choice when datasets are so heterogeneous such as the ones used for the development of \textit{EEGAVI}.

\subsection{Sharding}
Due to hardware limitations during pretraining, samples are stored in data shards using the \textit{h5py} library that uses the HDF5 storage format \cite{collette2013python}.
This choice affects the data loading strategy, as HDF5-based storage is more efficient when samples are read sequentially rather than through random access.
This means that reading directly from  the shards reduces the degree of reshuffling during training.
To avoid this problem, a buffer of chunks obtained from multiple shards is kept in memory.
In the experiments, this size was set to twice the size of the chunk's unit.
It is populated by sampling a shard in random order and loading its blocks sequentially.
This allows the loading pipeline to apply different permutations to the shards and filling the buffer with distant samples in storage order.
To further enforce randomness, the choice of samples of a batch is tied to the remaining size of the cached blocks, favoring larger blocks.
This makes the consumption of the in memory stored samples more balanced favoring stronger remixing.
Such approaches are common in large scale training settings, where they provide a practical compromise between I/O efficiency and sample randomization. \cite{hdfgroup_chunking}

The model is a deep neural network that handles a multimodal input sample.
Each modality of the sample is passed through a frozen encoder and then processed independently, via \textit{Modality Adapters}.
On these representations \textit{KD} is performed for video, audio and text.
After this, the data pass through the core element of \textit{EEGAVI}: the \textit{gated cross-attention} module.
The model performs pivot-centric cross-modal conditioning followed by intra-modal re-integration.
The information is condensed in an outputted \textit{CLS} token in addition to the full embeddings.

\subsection{Modality adapters}
Before committing to the fusion and after passing through the frozen encoder inputs pass through custom neural blocks.
These are required to match the interface of the various modalities to aggregate.
They also enforce the inputs to be rescaled to match the other modalities in the later layers of the model, allowing stronger alignment earlier in the architecture.
Another thing to consider is that the encoders chosen for all modalities are not specifically trained on affective data. By adding these adapters the model is able to capture affective information before starting the fusion process.

\textit{ECG} and \textit{EEG} are from a structural stand point less complex compared to other modalities.
For this reason they both adopt a simple masked non linear feed forward adapter.
\textit{EEG} are also reshaped to match requirements for the later \textit{cross-attention} mechanism by unflattening channels and the feature dimension.

\subsubsection{Perceiver Resampler}
The \textit{Perceiver Resampler} was proposed in the \textit{Flamingo} paper.
It takes inspiration from the \textit{Perceiver} model \cite{}.% todo
Its goal is to be able to elaborate all different kind of shapes to standardize acting as a compressor.
In the model's training process, input data was always of the same relative shape so its contribution was towards compression.
It uses a set of fixed learnable parameters, \textit{latents}.
These condense the feature of the inputs.
The compression is achieved by an attention mechanism.
When proposed, the module was defined on text and image interleaving which is not characterized by a time scale, unlike the current setting.
Given the strong temporal grid around samples, the module was adapted to not work on the time domain. The custom implementation also handles the masking of the inputs that is a core feature of the model's elaboration.

Methods like \textit{Perceiver Resampler} have shown to work well on large sets of embedding dimension. For this reason it is used for video and audio inputs.

\subsection{Knowledge distillation}
Beyond the given reasons, another strong motive that led to require modality adapters is the use of \textit{knowledge distillation} in the training process.

\textit{KD} is achieved in the model for text, audio and video.
It happens before fusion, and for each modality the distillation branch is meant to be present only during training.
For this reason, for \textit{KD} to affect the model during propagation, considering embeddings come from a frozen state, there is a need for trainable parameters prior to its application.

For \textit{KD} to be more effective the projection towards the teachers shape is kept minimal without any non linearity. This avoids the possibility of creating a module that is able to perfectly align with the teacher alone.
Thus, it enforces the backpropagation signal to be stronger on the adapter module,
shaping it to capture the information coming from the teacher.

To align the teacher and the student, the \texit{SigLIP} loss was used.


\subsection{Fusion and gatedXAttention}
The model is \textit{EEG} centric.
It builds the attention mechanism by taking the \texit{pivot} as $Q$ and
the concatenated \textit{supports} as $K,V$.
The supports pass through a \textit{modality encoder} before concatenation.
It adds a weight embedding constructed from the total amount of modalities, with an entry matching each.
The corresponding vector is added to the input as a tag, providing the subsequent cross-attention block with explicit information about the origin of each token.
An additional normalization step is then applied to keep the support representations in a more homogeneous feature space before fusion.

The \textit{gated cross-attention} mechanism is then deployed.
First, it applies \textit{cross-attention} between the \textit{pivot} \textit{EEG} embeddings and the concatenated \textit{supports}.
In this operation, each \textit{EEG} token fills the role of query ($Q$) and is matched against the support derived keys ($K$) to compute attention weights.
These are used to retrieve a weighted combination of the corresponding values ($V$).
This allows each \texit{EEG} token to selectively retrieve from corresponding values the most relevant complementary information.
In this way, supporting modalities do not replace the pivot representation, but enrich it through attention related updates.

\texit{Cross attention} is then followed by \textit{self-attention} over the updated tokens.
This allows the information that was merged at different time patches to interact and propagate beyond local injections.
Lastly, a \textit{feed-forward} block increases expressive power by introducing non-linearity beyond the linear attention mixing.

Like the standard transformer block \cite{}, each sub-layer is applied within a residual formulation.
This makes \textit{EEG} embeddings  augmented to integrate multi-modal information.
The attention used by the model is pre-norm, aligning to today's standard while also being able to handle masking correctly for both missing modalities and padded temporal positions.
All steps are controlled through a learnable \textit{gate} that weights the contribution of each intermediate step to the input of the sequence.
The learnable gate acts as an adaptive residual coefficient, allowing the model to regulate the contribution of each sub-layer update rather than injecting it with fixed strength.
The final model is composed of a total of 6 \texit{gated cross-attention} modules stacked on top of each other.
This allows for progressive refinement, making it possible for the EEG representation to integrate multi-modal evidence over several interactions rather than through a single fusion operation.

Although the model is capable of handling causality instead of bidirectionality to some extent, it is used as a learning trick to make the learning process more robust.
This means that the final model is designed for bidirectional use and, therefore, it is not able to process online inputs with the same capacity as it would when having the full sequence.



The student is drawn towards the teacher's representational space with SigLIP loss, defined later.

Since the model is masked on at all stages, to ensure stronger generalization capabilities, sample-modality level dropout is performed.
Each sample of the batch with a set probability $p$ can be masked out during the whole process downstream.
This should allow the model to better manage the data in situations where supporting modalities might be missing.

\section{Training Strategy}
This section describes the training process of the proposed model, from batch construction and optimization to the practical choices used to stabilize training.

The model adopts \textit{AdamW} as optimizer and uses \textit{SigLIP} loss for contrastive alignment on both fusion embeddings and \textit{KD} outputs.

\subsection{Data Loading and batch construction}

that i draw samples from 1 ds t a time

Mixing data is generally a good practice but in the context of EEG it can be a limitation.
We decided to make training batches built only from one dataset at a time.
This technique allows training batches to present generally harder situations for the model to separate, a phenomenon shown to improve learning in contrastive setups.
The negative samples drawn from the queue built by MoCo ignore the dataset.
This allows the model to still combine samples coming from different datasets during the loss computation.

The datasets used to train \textit{EEGAVI} are not of the same size as reported in \ref{}.
To avoid the model becoming too biased towards the most numerous dataset in terms of samples, the batches are built by following the power-law:
$$P(i) = \frac{n_i^\alpha}{\sum_{j}{n_j^\alpha}}$$

By setting $\alpha=0.5$ it became square-root sampling.
This preserves the relative prevalence of larger datasets while also balancing their dominance through non-linear down-weighting.
For this reason, when referring to an epoch of the model, stochastic sampling is unlikely to make it an exact pass.




\subsection{Objective}
\textit{EEGAVI}'s  training objective is defined as the weighted sum of the of the fusion and  knowledge distillation losses ($\lambda_{fusion}=1,\lambda_{kd}=0.5$):
$$ \mathcal{L} = \lambda_{fusion} \mathcal{L}_{fusion}  + \lambda_{kd} \mathcal{L}_{kd}$$


For  contrastive alignment, the \texit{SigLIP} loss was used with learnable \texit{bias} and $\tau$ temperature, one instance per modality.

The fusion loss is computed in modality pairs always comparing the output embeddings of the model, $z_{fused}$ with the fusion modalities ($z_{vid}, z_{aud}$...).
This reverse mapping allows to graps if the information contained in the fused output is able to recognize its source.
Strong alignment indicates that the information contained in a modality was transferred to the condensed embedding successfully.

The \texit{KD} fusion term is instead computed from the outputs of the \textit{KD} module of each participating modality w.r.t. of the matching output embedding of the teacher.

\subsection{Optimizer and learning rate schedule}
% TODO citations
The model was trained with \textit{AdamW} \cite{} a standard stable optimizer in contrastive learning setups.
Compared to \textit{Adam} with standard L2 regularization, \textit{AdamW} decouples weight decay from the gradient-based parameter update, yielding a cleaner and more controllable form of regularization.
A common practice that interacts well with \texit{AdamW} that was adopted to develop the model is a cosine scheduler on the learning rate \cite{}.
The process ramps up the learning rate for a set of warmup steps before slowly decreasing over the fixed duration of the training process hitting zero.
The model was trained with an initial learning rate of $3*10^{-4}$ with a total of 1000 warmup steps.
The \textit{lr} is stepped per batch for a smoother evolution variable that is more consistent when using smaller batches, which is \textit{EEGAVI}'s case.
Not all learnable parameters are decayed by \textit{AdamW}, as \textit{EEGAVI} respects the standard implementations avoiding this practice on: embeddings, norms, biases, and gates.
Decay was set to $w=0.01$, a common standard value for most applications.

The inputs of the model define a temporal structure, this is an element controlled by the attention mechanism.
Inspired by other applications such as AntLM \cite{yu2024antlmbridgingcausalmasked}, instead of taking single position of the time control we opt for a dynamic training on the setting.
The model can elaborate the inputs in either \textit{causal} or \textit{bidirectional} setting.
When \textit{causal} is selected future time steps relative to the current in the attention mechanism are masked out,
this way the model only has prior information to generate the outputs.
The \textit{bidirectional} setting allows for the whole sequence to be attended to.
The AntLM model explicitly describes a unified framework that alternates between causal and masked in the field of language models.
We take the same idea by balancing with a random probability $p$ in what masking mode the next batch in training is.
To make training simpler in earlier steps bidirectionality is preferred becoming more causal in later stages of the training process,
controlled by a cosine ramp schedule.

Samples tends to be very large because of the multiple modalities and their representation shape.
For this reason training the model becomes memory demanding in large batch settings.
While learning with small batches itself is fine and helps with regularization in contrastive setups, it can be harmful.
\textit{SigLIP}\cite{zhai2023sigmoidlosslanguageimage} was therefore adopted as loss for training.
For its strength regarding low batch size
Generally speaking, SigLIP is less sensitive to batch size.\\
The reason for this is that SigLIP does not rely on softmax over in-batch negatives as it uses independent binary logistic losses.
There is therefore no global softmax normalization, thus the gradient does not depend on the number of negatives.

While this helps, to make training even more robust MoCo was used.
Standard values for the technique were initially used (momentum $m=0.99$, queue size $q=1024$) but will be fine-tuned in future work.
The use of MoCo grants the model a larger number of negatives samples to compute the loss from, acting as a stabilizer for training.

Mixing data is generally a good practice but in the context of EEG it can be a limitation.
We decided to make training batches built only from one dataset at a time.
This technique allows training batches to present generally harder situations for the model to separate, a phenomenon shown to improve learning in contrastive setups.
The negative samples drawn from the queue built by MoCo ignore the dataset.
This allows the model to still combine samples coming from different datasets during the loss computation.
